# Изменения

## 0.3.0 — Dauys Hunt

- Новое название, знак голосовой волны и тема с индиго, бирюзовыми и коралловыми акцентами.
- Экран входа/регистрации по email, личные пространства, выход и смена пароля.
- Защищённые сессии, scrypt, CSRF/Origin-проверки, ограничение попыток и запрет доступа к чужим записям/экспортам.
- Повтор пароля при регистрации; автоматический перенос старых совещаний в первый аккаунт.
- Google/Facebook authorization-code интеграции; ключи подключаются отдельно через .env.
- Мягкая шкала цвета поручений по сроку с текстовыми пояснениями, отдельный цвет выполненных задач.
- Локальный инструмент проверки казахской/смешанной речи с эталоном и WER/CER. Проверка точности на таких аудиозаписях пока ожидает исходные файлы.


## 0.2.0

- Единый комплект SVG-иконок. Подсказки появляются через 1,5 секунды при наведении и фокусе с клавиатуры; уход курсора, прокрутка и Escape их закрывают.
- Новый визуальный акцент главной страницы, адаптивная вкладка инструментов; обновление данных без постоянного сброса интерфейса.
- Локальный кэш идентичных записей: учитывает содержимое файла, дату, язык, число говорящих, режим и версию конвейера. Повторный импорт получает отдельные поручения без копирования пользовательских статусов.
- Ранний просмотр распознаваемого транскрипта, таймер обработки, активность генерации и фактические времена этапов.
- Быстрый режим распознавания (beam 1) и точный (beam 3); пропуск ненужной кластеризации для одного говорящего.
- Поиск реплик с соседним контекстом, радар проверки поручений и распределение времени речи.
- Повестка следующей встречи из открытых поручений; ICS для проверенных задач с подтверждённой датой.
- Ручное добавление пропущенного поручения со ссылкой на существующие реплики.
- Уточнён разбор казахских дат с годом перед днём и месяцем.
- CI на Windows/Linux и автоматический архив GitHub Release после успешных проверок.

## 0.1.0

Первый локальный конвейер: аудио → транскрипт и говорящие → поручения и саммари → PDF/DOCX, SQLite и веб-интерфейс.
