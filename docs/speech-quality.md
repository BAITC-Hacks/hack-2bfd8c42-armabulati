# Проверка казахской и смешанной речи

С версии 0.3.1 для **Қазақша** и **Қазақша + русский · шала қазақша** используется специализированная [kazakh-whisper-large-v3-turbo](https://huggingface.co/shyngys879/kazakh-whisper-large-v3-turbo), преобразованная в CTranslate2 INT8. Для русского сохраняется исходный Whisper large-v3-turbo. Веса и конвертер зафиксированы в `models.lock.json`; после установки всё работает локально.

В исходной реализации обнаружена ошибка: автоматическое определение языка выбирало турецкий/английский на казахской записи, а общий Whisper при принудительном `kk` зацикливался на слогах. `multilingual=True` мог заново выбирать посторонний язык на каждом фрагменте. Теперь язык декодирования фиксируется: `ru` для уверенно определённого русского, `kk` для казахского и смешанного режима. Режим `kk` не запрещает русские слова и использует задачу transcribe, а не translate. «Авто» предназначено только для RU/KZ; при неопределённом языке выбирается казахская модель и показывается предупреждение. Для преимущественно русской записи выбирайте «Русский».

Добавлены ограничение повторов, более чувствительное выделение речи и защита от повторяющихся слогов. Исключённые интервалы отмечаются в транскрипте, повреждённые Unicode-слова заменяются отметкой «неразборчиво». Если детектор выделил меньше четверти длинной записи, она обрабатывается целиком без удаления пауз. Такой результат, а также зацикливание или слишком короткий транскрипт требуют ручной проверки: автоматическое составление поручений приостанавливается. Это эвристики, а не универсальный детектор ошибок. В частности, уверенная, но неверная фраза может пройти проверку.

На локальном проблемном фрагменте новая модель перестала выдавать повторяющиеся слоги и дала казахские фразы. Это **не оценка точности**: эталонной ручной расшифровки нет; остаются пропуски и ошибки слов. Разговорная смешанная речь с переключением языков внутри предложения пока не проверена на размеченном аудио. Заявлять гарантированное понимание любой «шала-казахской» речи нельзя. Музыка, пение и перекрывающиеся голоса сложнее обычного разговора; приложение предназначено для совещаний.

Старые готовые протоколы не перезаписываются. Кнопка **«Распознать заново»** создаёт новый результат с выбранным языком, без использования прежнего кэша. Для обновления моделей остановите сервер и выполните `python scripts/setup_models.py`; потребуется интернет для скачивания весов и инструментов конвертации. Во время распознавания сеть не используется.

## Как воспроизвести проверку

Нужны реальные записи с согласованным использованием и вручную проверенные транскрипты в UTF-8. Желательно минимум несколько говорящих: чистая казахская речь; русский и казахский в разных репликах; переключение языков внутри одной фразы; разговорная речь и шум.

```powershell
.\.venv\Scripts\python.exe scripts/check_speech.py "C:\audio\kazakh.wav" --language kk --reference "C:\audio\kazakh.txt" --output data/kk-check.json
.\.venv\Scripts\python.exe scripts/check_speech.py "C:\audio\mixed.wav" --language mixed --reference "C:\audio\mixed.txt" --output data/mixed-check.json
```

Скрипт использует **те же настройки ASR, что приложение**, запускает только локальную установленную модель и ничего не отправляет в сеть. `--fast` выбирает быстрый режим; по умолчанию используется точный. Без `--reference` он сохранит транскрипт и время обработки, но не будет выдавать оценку точности. Запуск из консоли предполагает доступ владельца устройства к файлу; вход в HTTP-приложение для этого не используется.

WER — число замен/удалений/вставок слов, делённое на число слов эталона; меньше лучше. CER аналогично измеряет ошибки букв, без пробелов. Перед сравнением убираются регистр и пунктуация, применяется Unicode NFC; казахские буквы не заменяются русскими. WER может превышать 100% при большом числе вставок. Числительные, сокращения и разные допустимые написания требуют ручного анализа.

Эти метрики не проверяют диаризацию, имена, полноту поручений или правильность сроков. Нельзя переносить хороший результат на чистой записи на шумную разговорную речь. Для «шала-казахской» речи важно проверить настоящие переключения внутри фразы; склейка отдельных русских и казахских записей этого не доказывает.
