# Проверки Dauys Hunt

## Версия 0.3.0

23.09.2026, Windows/Python 3.12: **34 Python-теста и 7 JavaScript-тестов прошли**. Новые проверки: регистрация, пароль и сессии, выход/смена пароля, лимит попыток, CSRF/Origin, разделение аккаунтов на всех путях чтения/экспорта, одноразовая миграция прежних данных, OAuth state/cookie/replay и обмен кода с тестовыми ответами Google/Facebook, дедлайны и настройка режимов ASR.

В браузере на отдельной тестовой базе выполнены регистрация → рабочее пространство → выход → повторный вход; проверены карточки сроков и мобильная ширина 390 px. Горизонтального переполнения и ошибок JavaScript не обнаружено. На самом насыщенном красном фоне карточки контраст заголовка составляет 10,02:1, вторичного текста — 5,03:1 (по фактическим CSS-цветам браузера).

Социальный вход с настоящими OAuth-приложениями пока не проверен: ключи не предоставлены, по запросу пользователя подготовлены интеграция и инструкция. Качество казахского/смешанного аудио требует исходных записей с проверенным текстом; [методика и команды](speech-quality.md). Пользовательские записи не заменялись синтетическими результатами.

## Версия 0.2.0: аудиоконвейер и скорость

Дата: 23 сентября 2026. Среда: Windows x64, Python 3.12, CPU, 16 ГБ RAM, 6 потоков для моделей. Веса и движок зафиксированы в `models.lock.json`. Аудио, транскрипты и база остаются локально.

## Автоматические проверки

- 19 Python-тестов: логика, API, экспорт, кэш, инструменты, потоковый ответ модели и архив.
- 4 JavaScript-теста: подсказка скрыта до 1500 мс, отмена при уходе курсора, клавиатурный фокус и Escape, касания и удалённые элементы.
- Синтаксис `app.js`, `tools.js`, `icons.js`; компиляция Python.
- Браузер: адаптивный интерфейс при 390 × 844 и 1440 × 1000, появление подсказки с клавиатуры и закрытие по Escape; ошибок JavaScript не обнаружено.

Автотесты используют подмену ИИ и не измеряют качество моделей. GitHub Actions настроен на Windows/Ubuntu, но первоначальный запуск остановлен до начала шагов по причине ограничения аккаунта организации. Проверка Linux и автоматический выпуск остаются неподтверждёнными.

## Реальное аудио и кэш

Запись №2, режим `fast`, язык `mixed`, число говорящих автоматически, дата встречи для проверки 2026-09-23. Проверка выполнена через `scripts/smoke_test.py --repeat` с настоящими локальными моделями.

| Измерение | Первый импорт | Повтор с теми же параметрами |
|---|---:|---:|
| От отправки до обнаружения готовности клиентом | 303,72 с | 2,15 с |
| Время конвейера на сервере | 302,57 с | 0,037 с |
| Распознавание | 77,62 с | Использован кэш |
| Диаризация | 5,18 с | Использован кэш |
| Анализ локальной LLM | 219,18 с | Использован кэш |
| Реплики / поручения | 71 / 5 | 71 / 5 |

Клиент опрашивает сервер раз в 2 секунды, поэтому время клиента включает задержку опроса. PDF/DOCX проверены по HTTP-ответам и сигнатурам файлов; полная визуальная проверка всех вариантов длинных протоколов не выполнена.

Кэш ускоряет только идентичную запись при совпадающих настройках. Новый импорт получает отдельные идентификаторы и сброшенные статусы проверки. Ручные правки исходного совещания не копируются.

На первых 30 секундах записи №1 с уже загруженной ASR-моделью beam 3 занял 13,70 с, beam 1 — 12,99 с. Это небольшая разница на одном коротком фрагменте; быстрый режим может снизить точность. Основное время полного импорта занимает анализ текста. Ранний просмотр транскрипта и индикатор генерации позволяют видеть прогресс, но сами по себе не ускоряют модель.

## Границы качества

Ранее запись №1 (274,25 с) прошла полный конвейер и дала 8 поручений при вручную заданных 6 голосах. В эталоне — 10 поручений; полнота не достигла эталона. Качество RU/KZ и смешанного аудио не измерено на размеченной выборке. Число реплик и задач подтверждает выполнение конвейера, но не правильность каждого результата. Ответственных, сроки и основания необходимо проверить в редакторе.
